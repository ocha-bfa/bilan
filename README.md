# Bilan interactif 2026 — Burkina Faso

Bilan mensuel de la réponse humanitaire au Burkina Faso (OCHA Burkina Faso, section Gestion de l'information).

**Consulter :** https://ocha-bfa.github.io/bilan/

Application web statique (HTML/JS) servie par GitHub Pages. Les données sont lues en lecture seule dans Supabase (vues `bilan_*`, voir `sql/`). Chaque feuille s'imprime en A4 paysage.
